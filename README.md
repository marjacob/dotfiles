Dotfiles
========

Personal configuration files managed with [chezmoi](https://www.chezmoi.io/).

Configuration
-------------


```yaml
data:
  editor:
    size:
      x: 86
      y: 27
  font:
    name: Consolas
    size: 12
  git:
    mail: user@example.com
    user: user
  terminal:
    size:
      height: 43
      width: 132
```

### Windows

```shell
%USERPROFILE%/.config/chezmoi/chezmoi.yaml
```

### Linux

```shell
~/.config/chezmoi/chezmoi.yaml
```
